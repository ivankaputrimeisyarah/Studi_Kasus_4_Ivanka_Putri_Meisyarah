1. Di awal, saya membuat variabel produk pakai tipe data Dictionary {} untuk menampung data dasar: nama, harga, dan stok barang.
2. Saya menggunakan while True agar programnya terus menampilkan menu secara berulang, sampai kita sendiri yang milih opsi buat keluar.
3. Program akan mengecek dan menyetak isi produk satu per satu. Pakai kondisi if "kategori" in produk supaya baris kategori cuma muncul kalau variabelnya memang sudah pernah diisi.
4. Mengambil input teks dari user, lalu langsung dimasukkan sebagai key baru ke dalam dictionary dengan produk["kategori"] = ....
5. Mengambil input harga baru, diubah ke tipe angka/integer (int()), lalu menimpa nilai harga yang lama (produk["harga"] = harga_baru).
6. program mengecek dulu apakah key "kategori" ada. Kalau ada, dihapus pakai perintah del produk["kategori"]. Kalau belum ada, program kasih tahu kalau kategorinya kosong.
7. Perintah break dipakai buat nemputusin perulangan while True, jadi programnya berhenti.
